## The Challenge

Consolidating various smart-home devices from different brands under a single, locally controlled private dashboard without relying on external cloud APIs.

## The Process

I deployed Home Assistant Core on a Proxmox virtual machine, configured a Z-Wave network controller, mapped out various sensors and lights, and wrote YAML automation rules for smart switches and safety alerts.
